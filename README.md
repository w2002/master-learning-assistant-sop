# Master Learning Assistant SOP

一套面向**英文授课、英文考试硕士课程**的 AI × Obsidian 学习工作流。它的核心目标不是压缩 PPT，而是把课程材料重新组织成初学者真正能读懂、能够复习并最终用英文作答的知识体系。

## 项目解决的问题

英文专业术语会显著增加第一次学习的认知负担。传统双语对照容易让学习者停留在翻译层面，而高度压缩的 AI 摘要又会跳过关键推理。本项目采用两份相互链接、功能不同的笔记：

- **Chinese Learning Note**：课前三轮术语预热；中文讲清问题、机制、公式、最小例子和完整课程例题；保留正式英文术语与可迁移句型。
- **English-only Review**：在已经理解以后用于考前速记、knowledge map、exam-ready answer 与全英文自测，不做逐句中英对照。

## 核心工作流

1. 按教师实际授课顺序接收 PPT、讲义、录音转写和试题。
2. 先完成具有教学深度的中文学习版，再制作紧凑的纯英文复习版。
3. 用 PDF++ 彩色选区和双链记录课堂强调、例子、个人批注、待解决问题及明确考试说明。
4. 课后只把能够独立阅读、可迁移和反复使用的概念提炼为知识点。
5. 更新课程首页、知识点索引、制作状态和真实学习状态。
6. 检查来源覆盖、公式、表格、双链与版本归档。

## 设计原则

- 初学者先理解“为什么”，再记公式与答题模板。
- 中文承担第一次理解，英文承担复习和考试输出。
- 笔记制作完成不等于已经掌握。
- 课件、教师原话、AI 补充与用户批注必须区分来源。
- 讲次笔记不是知识点；知识点必须能脱离原讲次独立读懂。
- 历年试题用于验证与练习，不凭空声称“高频”或“必考”。
