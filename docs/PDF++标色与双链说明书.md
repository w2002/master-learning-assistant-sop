# PDF++ 标色、引用与双链说明书

返回 [[Master]] · [[Master学习助手SOP_v1.8|当前 SOP]]

## 先记住一句话

> [!important] 点击颜色不会自动把内容写进笔记
> PDF++ 的颜色按钮会把“带颜色和位置的 PDF 引用”复制到剪贴板。你还要回到 Markdown 笔记，在想放的位置按 **⌘V**。粘贴成功后，笔记中才出现指向该 PDF 选区的链接，PDF++ 才能把它识别为反向链接高亮。

因此，完整动作是：

**选择 PDF 文字 → 点击颜色 → 回到笔记 → ⌘V 粘贴 → 双链建立。**

## 本仓库已经替你配置好什么

- PDF++ 已启用，并使用链接式高亮，不直接改写原 PDF。
- 双击 PDF 高亮可打开引用它的笔记；鼠标悬停可预览反向链接。
- Obsidian 模板目录是：99_模板与规则/Obsidian模板。
- 插入模板快捷键是：**⌘⌥T**。
- 已配置与 PDF++ 一致的 Yellow、Green、Blue、Purple、Red 五种 Callout 颜色。
- 原来一次插入全部课堂框的模板已经移出活动模板库。

## 一、颜色片段模板怎么用

课堂笔记不再预先放五个空框。讲到哪里，就把光标放在相应正文旁边，只插入当前需要的颜色。

| 输入的搜索词 | 插入的片段 | 用途 |
| --- | --- | --- |
| Yellow | 课堂批注_01_Yellow_老师强调 | 老师明确重复、停留或强调 |
| Green | 课堂批注_02_Green_老师例子 | 老师补充案例、应用或演算 |
| Blue | 课堂批注_03_Blue_我的批注 | 你自己的理解、联想或跨章节连接 |
| Purple | 课堂批注_04_Purple_待解决问题 | 当场没听懂、需要课后查证 |
| Red | 课堂批注_05_Red_明确考试说明 | 仅记录老师明确说到的考试、作业或评分要求 |

### 最顺手的完整动作

1. 在 PDF 中选中最小但完整的一句话或矩形区域。
2. 点击 PDF++ 中相应的颜色，此时链接进入剪贴板。
3. 回到正式笔记，把光标放在对应概念旁边。
4. 按 **⌘⌥T**。
5. 直接输入颜色英文名，例如 Yellow，然后选择对应片段。
6. 模板插入后，光标位于彩色说明框下面的空行；立即按 **⌘V**。PDF++ 引用必须单独占一行，不能接在 Callout 的标题或说明后面。
7. 回到上一行，用一两句话补充老师强调什么、例子说明什么，或者你具体不懂哪里。

例如只需要老师强调时，就选择 Yellow。笔记中只会加入一个黄色框，其他四种颜色完全不会出现。

> [!warning] 不要把 PDF++ 引用粘在同一行
> 正确结构是“课堂说明 Callout”结束后空一行，再粘贴 PDF++ 自动生成的 `> [!PDF|颜色]`。如果把它接在 `**PDF source:**` 后面，Obsidian 会把两个 Callout 拼成普通文本，出现 `[!green]` 或 `[!PDF|green]` 直接显示的情况。

### 不需要 Callout 时

也可以跳过模板，直接在正文旁边按 **⌘V**。双链仍然有效；颜色片段模板只是帮助你保留统一的来源和说明结构。

### 颜色表示什么

颜色表示**来源和用途**，不表示内容天然重要。不要因为自己猜测某页可能会考就使用 Red。Red 只记录老师明确作出的考试、作业或评分说明。

## 二、双链到底是怎样形成的

当前 PDF++ 工具条使用 **Link** 复制格式。粘贴后，Markdown 笔记里会出现一个带页面与选区位置的内部链接，形式大致如下：

`[[课程课件.pdf#page=2&selection=...|课程课件，第2页]]`

你可以紧接着写自己的说明，例如：

> Lecturer's point: risk is both an input to and an output from strategy.

如果以后把 PDF++ 的复制格式改成 Quote 或 Callout，外观会不同，但只要保留带 page 和 selection 的 PDF 内部链接，双链原理不变。

这段链接做了三件事：

1. 笔记链接到 PDF 的具体页码和选区；
2. PDF++ 读取这个链接，并在 PDF 原位置显示虚拟高亮；
3. PDF++ 把包含该链接的笔记列为这个高亮的反向链接。

所以你不需要再手工建立第二条返回链接。**笔记里的选区链接本身就是双链关系的来源。**

### 从笔记回到 PDF

点击粘贴出的 PDF 链接。Obsidian 会打开相应 PDF，并定位到对应页面或选区。

### 从 PDF 回到笔记

- **双击高亮**：打开引用该选区的笔记；
- **鼠标悬停高亮**：预览反向链接；
- 如果同一选区被多篇笔记引用，PDF++ 会提供多个反向链接目标。

## 三、一个真实操作例子

假设老师讲 COURSE101 第03讲第2页，并强调 risk is an input to and an output from strategy：

1. 在 [[COURSE101_03_Global_Risk_Environment.pdf]] 第2页选中这句话；
2. 点击 **Yellow**；
3. 回到 [[COURSE101 第03讲 全球风险环境]] 的第1节，把光标放在相关段落后；
4. 按 **⌘⌥T**，输入 Yellow，选择“课堂批注_01_Yellow_老师强调”；
5. 模板出现后立即按 **⌘V**，再补充：

> **Lecturer's point:** risk is not only a threat identified after strategy has been chosen. The strategic choice itself creates new exposure.

以后点击该引用会回到第2页；在 PDF 中双击黄色高亮，会回到这篇笔记。

## 四、课件中的图和无法选中的文字

有些页面是图片，文字无法拖选。这时使用 PDF++ 的矩形区域引用：

1. 在 PDF++ 工具条选择矩形／区域选择工具；
2. 框住图表或局部区域；
3. 点击颜色；
4. 回到笔记，按 **⌘⌥T** 选择相同颜色的片段；
5. 立即按 **⌘V**，再写清楚该图说明什么。

矩形不要框整页。尽量只框能支持当前笔记结论的区域，否则复习时很难看出当时为什么保存。

## 五、板书照片怎么处理

板书照片与 PDF 选区不同：

1. 把原照片拖入当前正式笔记；
2. 在照片下写：日期、时间、对应主题或幻灯片、老师当时解释什么；
3. 需要圈画时，用 Excalidraw 打开或建立可编辑副本；
4. 原图保留，圈、箭头和补充文字放在 Excalidraw 副本中；
5. 把有长期价值的结论写回正式正文，不让知识只留在图片里。

## 六、你课堂上实际只需记什么

每次补充尽量包含两部分：

1. **证据或定位**：PDF++ 链接、板书照片或准确的课件页；
2. **一句有意义的说明**：老师补充了什么，这个例子证明什么，或你具体不懂哪里。

只粘贴一串链接而不写说明，课后很容易忘记当时为什么标记。只写说明而没有定位，又很难回到原文核对。

## 七、常见问题

### 点击颜色后什么都没有发生

这是正常表现之一：PDF++ 已经把引用复制到剪贴板。回到 Markdown 笔记按 **⌘V**。如果粘贴不出内容，重新选择文字并点击颜色一次。

### PDF 中没有看到高亮

先确认引用已经粘进并保存到 Markdown 笔记。链接式高亮由笔记中的链接生成；剪贴板里有内容但没有粘贴时，不会形成高亮。仍未出现时，关闭并重新打开 PDF，让 PDF++ 重新索引反向链接。

### 点击链接只到了页面，没有精确高亮

可能选中的是整页链接，或课件文字实际是图片。重新用文字选区或矩形区域选择，点击颜色后再粘贴。

### 双击高亮没有回到笔记

先检查笔记里是否确实存在该选区链接，并保存笔记。若同一高亮对应多个笔记，先从反向链接列表选择目标。

### 粘贴到了错误位置

直接剪切整段 PDF callout，再粘到相关概念下方。链接中的页面和选区不会因移动而失效。

### 删除笔记里的引用会怎样

该选区与这篇笔记之间的反向链接会消失；PDF++ 重新索引后，对应的虚拟高亮也会消失。原 PDF 不会被修改。

### 为什么不使用“直接写入 PDF”

本仓库关闭了 PDF 直接编辑。链接式高亮更适合知识库：原件保持不变，颜色、说明和双链都由 Markdown 笔记管理，也更容易修改和迁移。

1. PDF 选中文字或区域并点击颜色。
2. 回到正文相关位置，按 **⌘⌥T**。
3. 输入 Yellow / Green / Blue / Purple / Red。
4. 选择同色片段，立即按 **⌘V**。
5. 补一句有意义的上下文。
6. 点击笔记链接回 PDF；双击 PDF 高亮回笔记。
