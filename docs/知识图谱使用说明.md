# 知识图谱使用说明

## 默认图谱显示什么

全局关系图谱默认采用“独立知识点视图”，只保留：

- 各门课程的课程首页；
- 各门课程的知识点索引；
- `03_知识点` 中可复用的概念与方法。

模板、SOP、原始课件、习题、历年试卷、复习记录以及 `02_随堂学习` 中的中文学习版与 English Review 仍然保留在仓库中，但不进入默认图谱。讲次笔记是完整课程材料，不是知识点节点。

链接到“中文学习版#某标题”的条目只算**讲次导航**。只有实际建立在 `03_知识点/`、可以独立阅读的概念或方法页，才算知识点。

可按自己的课程设置颜色，例如：

| 颜色 | 课程 |
| :---: | :--- |
| 红色 | Course A |
| 黄色 | Course B |
| 黄绿色 | Course C |
| 绿色 | Course D |
| 青色 | Course E |

## 日常学习时怎么用

全局图谱适合观察一门课程已经形成了哪些主题簇，以及哪些知识点仍然孤立。真正学习某一讲时，优先打开该讲笔记，再从笔记右上角菜单打开“局部关系图”。

- 深度 `1`：查看这篇笔记直接连接了什么，适合上课与第一遍复习。
- 深度 `2`：查看相邻知识点之间的联系，适合章节复习。
- 不建议日常把深度开得更高，否则又会恢复成难以阅读的网络。

## 临时查看其他内容

打开关系图谱右上角的筛选按钮，可以修改“搜索文件”中的检索式。

默认检索式为：

```text
path:"01_课程" -path:"01_课程资料" -path:"02_随堂学习" -path:"04_习题与作业" -path:"05_历年试卷" -path:"06_复习与疑问" -file:"课程目录"
```

- 想把全部逐讲笔记临时放回图谱：删除 `-path:"02_随堂学习"`。
- 想看完整仓库：清空整个检索式。
- 想恢复独立知识点视图：重新粘贴上面的默认检索式。

## 怎样审计提炼状态

课程笔记包含实质知识，并不代表知识点已经独立提炼完成。可以定期比较两类数量：

- `03_知识点/` 中能够独立阅读的知识点文件；
- 指向逐讲笔记标题的讲次导航。

如果一门课程的讲次导航很多、独立知识点很少，说明内容已经写入课程笔记，但可复用概念仍待提炼。这里的“零个独立知识点”不表示课程没有知识内容。默认图谱可以承担审计作用：图谱稀疏提示提炼工作尚未完成，不应再用整篇逐讲笔记填满画面。

对于旧课程，可把待提炼内容记入课程首页，等需要复习该讲时再回溯处理；对于新课件，逐讲笔记与独立知识点应尽量在同一次整理中完成。

## 以后新增知识点的规则

1. 一般解释留在对应讲次的中文学习笔记中。
2. 只有会跨讲次复用、需要反复回看的概念，才单独建立知识点笔记。
3. 知识点笔记放入该课程的 `03_知识点`，并至少链接回一篇讲次笔记或课程首页。
4. 跨课程确实存在概念关系时才建立双链，不为了让图谱“看起来密”而添加链接。

图谱是笔记关系的结果，不是学习目标。课程首页负责汇总，逐讲笔记负责理解，知识点笔记负责复用。
